## Topics Covered

- Physical infrastructure, virtualization, and server roles.
- Requirements gathering for the 15-server classroom scenario.
- Rack placement, power paths, and shared failure dependencies.
- PSU terminology, cooling, physical access, and facility responsibilities.
- Azure resource groups and governance foundations.
- CapEx versus OpEx.
- Azure Virtual Desktop terminology and cost assumptions.
- SLA response targets, service restoration, and incident priority.
- Shared broadband versus dedicated internet.
- Local network traffic versus internet traffic.

## How to Use the Quiz

1. Review your Day 01 study notes.
2. Open the live quiz using the link above.
3. Select **Start 20-minute quiz** when ready; the timer begins then.
4. Choose one answer for each question.
5. Select **Submit answers** to finish early. When time expires, the quiz submits automatically.
6. Read the explanations, especially for incorrect and unanswered questions.
7. Revise the relevant topics before starting another attempt.

Green highlights indicate the correct option. Red highlights indicate an incorrect selection. Use **Print / Save as PDF** after submission to retain your review if needed.

## Learning Goals

After revision, aim to explain:

1. How physical infrastructure, virtualization, and cloud differ.
2. Why workload requirements should be established before selecting server count or size.
3. How servers in different racks can still share a failure dependency.
4. Why later hardware purchases can still qualify as CapEx.
5. How response, restoration, and incident resolution differ.
6. Why a CPU percentage alone does not determine incident priority.
7. How local network capacity differs from ISP internet capacity.
