## Learning Objectives

After reviewing this lesson, you should be able to:

- Distinguish physical infrastructure, virtualization, and cloud computing.
- Identify compute, storage, and networking resources.
- Explain the basic purpose of Azure Virtual Desktop and monitoring.
- Gather requirements before accepting a request for 15 servers.
- Recognize shared dependencies involving power, racks, networking, and facilities.
- Explain private and shared data-center arrangements.
- Distinguish CapEx from OpEx.
- Explain SLA priorities, response, restoration, and resolution.

4. Why can hardware purchased later still be CapEx?
5. What is the difference between response, restoration, and resolution?

## Technical Clarifications to Remember

- **CapEx:** buying hardware later does not automatically make it OpEx; the nature of the expenditure and applicable accounting policy matter.
- **Shared dependencies:** separate racks can still depend on the same power, network, storage, cooling, or site.
- **SLA timings:** classroom examples are not universal commitments. Confirm targets and clock definitions in the actual agreement.
- **Restoration and resolution:** a workaround can restore service before permanent corrective work is complete.
- **Resource groups:** an Azure resource group is a logical container for related resources, rather than simply a collection of servers.
- **AVD billing:** signing out does not automatically deallocate a session host or eliminate every resource charge.
- **Networking shorthand:** “local = free” and “public = paid” are not complete technical definitions or universal charging rules.
- **Support levels:** certification does not automatically establish an employer's L1, L2, or L3 role.
